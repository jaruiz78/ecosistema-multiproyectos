# AGENTS.md - Core Algorítmico core-interstellar-mesh (Google Antigravity)

Módulo algorítmico híbrido Python/Java del Gemelo Digital Unificado. Opera como biblioteca de cálculo y modelización sin persistencia directa.

## 1. Mapeo de Intención a Skill (SDLC 6-Phase Dispatch)
- **Nueva Funcionalidad:** `spec-driven-development` -> `planning-and-task-breakdown` -> `incremental-implementation` -> `zero-mockito-tdd-engineer`
- **Modelización Matemática:** `math-modeler` -> `unified-twin-node-injector`
- **Bugs o Refactorización:** `debugging-and-error-recovery` -> `doubt-driven-development`
- **Simulación y Gemelo Digital:** `digital-twin-enkf-orchestrator` -> `simulation-telemetry-sqlite-analyzer`

## 2. Reglas del Módulo
1. **Biblioteca Algorítmica Pura:** Cero dependencias de infraestructura. Sin persistencia directa.
2. **Python Científico & Java 25:** NumPy/SciPy para cálculo numérico, Java Records para interfaces de dominio.
3. **Cero Simulaciones Aisladas:** Todo cálculo predictivo debe formularse como tensor e inyectarse en `tensor_gnn_core.py`.
4. **Grounded Docstrings Obligatorios:** `@see docs/formacion_ecosistema/UNIVERSIDAD_PRIVADA_ECOSISTEMA_CURRICULUM.md`.
5. **Testing Estricto:** pytest + JUnit 5. Tests de convergencia y precisión numérica obligatorios.

## 3. Integración con Gemelo Digital
- Toda salida debe ser inyectable como tensor en `tensor_gnn_core.py` (Meta-Bucle 3).
- Inputs geográficos indexados bajo malla Uber H3.
